Flag decoder

Type a value to see which flags are set in it. The first flag is worth 1, the second 2, the third 4 and so on, the same numbering as the Int and Binary columns in Tree leaf paths. Tick flags in the list to go the other way and build a value.

Value

Int also takes sums like 1+4+8. A 0b or 0x prefix reads the value as binary or hex, whichever notation is picked.
