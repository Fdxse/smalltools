IP subnet calculator

Type an IPv4 or IPv6 address with its prefix or mask to get the network, mask, address range and size. You can also split the network into smaller subnets and check whether an address belongs to it.

Address

Takes 192.168.1.10/24, 192.168.1.10 255.255.255.0, a wildcard mask such as 192.168.1.10 0.0.0.255, or 2001:db8::1/64. An address with no prefix is read as a single host.

    Bits

    Bold, tinted bits are the network part. Plain bits are the host part.
