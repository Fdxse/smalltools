Decision table

Every combination of up to 8 two-state fields, with an Expected result column. Write a few rules and the result fills itself in: the first rule that matches a row wins, and rows no rule matches get the default result.

Fields

Rules

Pick a state for the fields the rule cares about and leave the rest on “Any”. All picked states must match. Rules are checked from top to bottom.
