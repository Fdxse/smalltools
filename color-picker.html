Color picker and contrast checker

Pick a color or paste one in any CSS format to convert it. Then check two colors against the WCAG contrast rules, and get the closest colors that pass.

Color

Takes #2457d6, #25d, rgb(36, 87, 214), 36 87 214, hsl(223, 71%, 49%), oklch(49% 0.19 264), color names such as rebeccapurple, and anything else your browser reads as a CSS color.

    Button or input border
    Large text is at least 24 px, or 18.66 px when bold. WCAG has no AAA level for buttons and icons. The ratio is rounded down, so a value that only just fails does not look like a pass.
